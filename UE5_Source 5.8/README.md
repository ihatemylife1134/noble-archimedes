# Noble Archimedes — UE5 Chapter 1 rebuild

Private-use fan rebuild of *Castlevania: Curse of Darkness* (PS2, SLUS-21168) in
Unreal Engine 5. Chapter 1 is playable end to end: walk in, fight the entrance hall
encounter, clear the chapel, reach the boss arena, unlock the save room.

All geometry, animation, materials and code are generated by the scripts in this
repository. No original game assets are included.

## Layout

```
NobleArchimedes.uproject
BuildScripts/          build, launch and quality-gate scripts
Config/                project settings (input, rendering, navigation)
Content/               UE assets plus the design specs that generate them
  Blueprints/*.md      animation, combat, level and asset specifications
  DataTables/          weapon, enemy and progression tables
ArtSource/Hector/      Blender scripts that generate Hector's mesh and 12 clips
Source/
  NobleArchimedes/     runtime module: character, combat, rooms, save, HUD
  NobleArchimedesEditor/ editor-only authoring for the animation graph
Tools/                 UE Python content pipeline and verifiers
```

## Requirements

- Unreal Engine 5.8
- Visual Studio 2022 with the C++ game development workload
- Python 3 for the content tools
- Blender, only when regenerating Hector's mesh or animation (see below)

## Build and run

```
BuildScripts\build_dev.bat          # compile the editor target
BuildScripts\open_editor.bat        # launch the editor for Chapter 1
BuildScripts\play_game.bat          # run the game directly
```

In the editor, press **Alt+P** to play.

## Content pipeline

The level, blueprints, data tables, animation graph and art pass are all generated
from scripts, so the project can be rebuilt from source:

```
python Tools\ue5_build_content.py     # blueprints, data tables, level blockout, anim graph
python Tools\ue5_art_pass.py          # materials, set dressing, lights, enemy meshes
python Tools\debug_full.py            # 58-check gameplay audit
python BuildScripts\run_quality_gate.ps1   # runs all of the above plus fidelity and smoke tests
```

The quality gate is the source of truth for whether the project is healthy. It
fails fast and reports a PASS/FAIL table.

## Regenerating Hector's art

The mesh and all 12 animation clips are generated by Blender:

```
BuildScripts\regenerate_hector_art.ps1
```

This writes FBX into `ArtSource/Hector/Export/`, which the content build imports.
Re-run the content build afterwards so the clips reach the animation blueprint.

## Known open items

- Hector and the enemies hold their arms out in front: `hector_anims.py` rotates
  the arm on the wrong axis for a T-posed rig. The source is corrected but the FBX
  has not been regenerated (needs Blender).
- Enemies reuse Hector's mesh and clips; dedicated enemy art is missing.
- Asset coverage is 26/75 with no presentation assets (audio, VFX, UI).
- Four attack clips drift from the 60 fps frame data used for combat timing.
