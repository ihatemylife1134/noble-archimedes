# Level Design Specification — Extended

This document provides detailed level layout information for all 10 chapters,
based on the Bradygames guide and PS2 disc analysis.

## Chapter 1: Abandoned Castle

### Layout Overview
```
Entrance Hall ──► Chapel ──► Save Room ──► Boss Arena
     │              │              │           │
     └──────────────┴──────────────┴───────────┘
```

### Room Details

| Room | Size | Enemies | Exits | Items | Lighting |
|------|------|---------|-------|-------|----------|
| Entrance Hall | Large | 3 Skeletons, 2 Zombies | Chapel, Save Room | Short Sword recipe | Torches (dim) |
| Chapel | Medium | 2 Ghouls | Entrance Hall, Boss Arena | Potion x2 | Candles (flickering) |
| Save Room | Small | None | Entrance Hall | None | Warm glow |
| Boss Arena | Large | Sentinel Knight | Chapel | None | Dark, spotlight on boss |

### Secrets
- Breakable candles in Chapel drop Potions
- Hidden alcove in Entrance Hall contains extra Iron Shards
