# Level Specification — All 10 Chapters

This document specifies level layouts, room connections, and objectives
for all 10 chapters, based on the Bradygames guide.

| Room Name | Type | Enemies | Exits | Special |

## Room Lock System
- Rooms lock when enemies enter (red bars drop)
- Rooms unlock when all enemies defeated
- Cleared rooms remain unlocked on return
- Save rooms are always unlocked

## Save Room Mechanics
- Fully heal player and all Innocent Devils
- Auto-save on entry
- Manual save available from pause menu
- Visual: glowing floor tile

## Candle Mechanics
- Breakable light sources in each room
- Drop items: Serum, Uncurse, Potions, High Potions (last two levels only)
- Visual: flickering flame, breakable on attack
